# AGENTS.md

## Repo layout

pnpm workspace (root `pnpm-workspace.yaml`) manages two frontend packages:
- `vue-web/` — Vue 3 + Vite 8 + Tailwind v4 + Pinia SPA (main site)
- `tldraw-web/` — React 19 + tldraw drawing tool

Other directories are **not** workspace packages:
- `api/` — Go 1.24 BFF (Echo v4, GORM/SQLite, S3 via MinIO client). Module path: `grd0.net/api`
- `workers/sitemap-generator/` — Cloudflare Worker (wrangler), serves `grd0.net/sitemap.xml`
- `assets-helper/` — Standalone Node scripts (own lockfile, pnpm 10)
- `assets/` — Static content gitignored; uploaded to Cloudflare R2
- `docs/api/` — Restfox API collection (not Bruno despite README claim)

## Commands

```bash
# Install all workspace deps
pnpm install

# vue-web
cd vue-web && pnpm dev              # vite dev server on :5173
cd vue-web && pnpm build            # runs type-check + vite build in parallel
cd vue-web && pnpm type-check       # vue-tsc --build --force
cd vue-web && pnpm lint             # eslint (vue + ts + prettier)
cd vue-web && pnpm format           # prettier --write src/

# tldraw-web
cd tldraw-web && pnpm dev
cd tldraw-web && pnpm build         # tsc -b && vite build
cd tldraw-web && pnpm lint

# Go API (from repo root)
cd api && go build -o ../grd0_blog_api .
cd api && go run .

# Assets TOC generation (writes api/data/files/files.json)
cd assets-helper && pnpm run generate

# Assets upload to R2
cd assets-helper && bash upload.sh  # requires rclone configured

# Full web build (tldraw then vue)
bash build-web.sh
```

## Data flow

`assets/` → `assets-helper/toc-generator.js` → `api/data/files/*.json` → API reads JSON at runtime → Vue web fetches via `api.grd0.net`

JSON files consumed by API: `blogPost.json`, `galleryDetail.json`, `galleryCollection.json`, `travelersMap.json`, `files.json`, `music.json`. These are **not** in git; regenerate with the TOC generator.

## Key gotchas

- **No tests exist** anywhere in the repo. Do not invent test commands.
- **Prettier**: no semicolons, single quotes, `trailingComma: "none"`, `printWidth: 100`.
- **`components.d.ts`** in vue-web is auto-generated by `unplugin-vue-components` — do not edit manually.
- **API Dockerfile** builds from repo root context: `cd api; go build -o ../grd0_blog_api`.
- **API CORS** only allows `http://localhost:5173` and `https://grd0.net`.
- **API listens on `:80`**, not a typical dev port.
- **`assets-helper/`** has its own `pnpm-lock.yaml` and uses pnpm 10 (not 11). Install separately if needed.
- **vue-web build** runs type-check and vite-build in parallel via `run-p`; type errors fail the build.
- **Tailwind v4** uses the `@tailwindcss/vite` plugin — no `tailwind.config.js`.
- **PostCSS** only has `css-has-pseudo` plugin (for `:has()` selector polyfill).
- **`api/data/files/`** is empty in git; content comes from the `grd0-site-data` sub-repo or TOC generator.
- **README is auto-generated** (stated in its first line) and often inaccurate. Trust config files over README.
- **Vue path alias**: `@` → `./src` (configured in `vite.config.ts`).

## Environment

- **vue-web**: `.env` sets `VITE_API_URL` and `VITE_ASSETS_URL` (defaults to production `https://api.grd0.net` / `https://assets.grd0.net`).
- **api**: needs `AUTH_JWT_SECRET`, `S3_ENDPOINT`, `S3_ACCESS_KEY_ID`, `S3_SECRET_ACCESS_KEY`, optionally `DB_PATH` (default `data/api.db`), `LAMBDA=TRUE` enables in-memory JSON caching.
